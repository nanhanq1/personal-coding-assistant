# Week 4 Day 4-Day 7 实现记录归档

## Week 4 Day 4 shell gate

- 新增 `tests/test_permissions_shell_gate.py`。
- 将 `ShellCommandTool._run(...)` 接入 `classify_command(...)` 和 `PermissionPolicy.decide(...)`。
- `DENY` 和 `ASK` 在进入 `ShellRuntime.run(...)` 前抛出 `PermissionError`，由 `ToolRegistry.run(...)` 转成失败 `ToolResult`。
- `ALLOW` 保持原 shell runtime 执行路径。
- 函数形式 `run_command(...)` 改为走 `ShellCommandTool().run(arguments)`，避免绕过 gate。

## Week 4 Day 5 文件风险分类

- 新增 `src/pca/permissions/file_risk.py` 和 `tests/test_permissions_file_risk.py`。
- `write_file` 新文件分类为 `SAFE`，覆盖已有文件分类为 `ASK`。
- `edit_file` 小范围替换分类为 `SAFE`，空字符串替换或大范围缩减分类为 `ASK`。
- `WriteFileTool` / `EditFileTool` 在写盘前接入 permission gate，证明覆盖写入失败且磁盘内容不变。

## Week 4 Day 6 审计事件

- 新增 `src/pca/permissions/audit.py` 和 `tests/test_permissions_audit.py`。
- 定义 `PermissionAuditEvent` 和 `append_audit_event(...)`。
- audit 只记录事实，不改变 `ALLOW / ASK / DENY` 行为；尚未自动接入 shell/file gate。

## Week 4 Day 7 权限系统验收示例

- 按 TDD 更新 `tests/test_examples.py`，新增 `test_permission_agent_example_reports_allow_deny_and_ask_paths`。
- 先确认 RED：`examples/04_permission_agent.py` 不存在。
- 新增 `examples/04_permission_agent.py`。
- 示例展示安全 shell 命令 `ALLOW` 后进入 runtime。
- 示例展示 `rm -rf danger-zone` 命中 `DENY`，在 shell gate 前失败。
- 示例展示 `python -c ...` 命中 `ASK`，在没有审批 UI 时失败返回。
- 示例展示新文件写入成功、覆盖已有文件被文件风险 gate 拦截，且文件内容保持不变。
- 示例输出 `capability_boundary`，明确当前没有交互式审批恢复、checkpoint、rollback、sandbox 或 audit 自动接入。
